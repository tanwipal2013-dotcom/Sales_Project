# Sales_Project
This report provides a professional-level view of business performance, focusing on sales, orders, order date, product category, regions, customers, and discount impact. It is designed to support data-driven decisions and is directly adapted to a Power BI sales dashboard.
# Tools Used
- Power BI
- Excel
- MYSQL
# Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Total Quantity Sold
- # Dashboard Features
- Sales by Region
- Sales by Product Category
- Top 5 Products
- Top 10 Customers
- Profit Analysis
- Discount vs Profit Analysis
- Monthly Sales Trend
- # Key Insights
1. Identify the highest-performing region.
2. Identify the most profitable products.
3. Analyze the relationship between discount and profit.
4. Compare sales performance across categories.
